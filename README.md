# 고객 정보 입력 도구

보험 고객 정보를 탭별로 관리하고, 각 필드를 클립보드로 빠르게 복사할 수 있는 웹 도구입니다.

## 주요 기능

- **탭 관리** — 여러 탭을 만들어 고객 그룹별로 분리 관리
- **고객 카드** — 탭당 여러 명의 고객 정보를 카드 형태로 입력
- **자동 파싱** — 고객 정보를 복사해서 빈 공간에 붙여넣으면 이름, 주민번호, 전화번호, 통신사, 주소를 자동으로 인식해서 각 칸에 입력
- **클립보드 복사** — 각 필드 옆 복사 버튼으로 원클릭 복사
- **전체 적용** — 통신사, 주소, 직업 등을 탭 내 전체 고객에게 한 번에 적용
- **보험사 선택** — 삼성, KB, 메리츠 등 10개 보험사 선택 및 `이름 동의 보험사` 형식으로 복사

## 자동 파싱 지원 양식

아래 형식의 텍스트를 복사한 뒤 페이지 빈 공간에 붙여넣으면 자동 입력됩니다.

```
홍길동
9001011234567
010-1234-5678
SKT
서울시 강남구 테헤란로 123
456호
```

한 줄로 붙여넣어도 인식됩니다.

## 사용 방법

1. **탭 추가** 버튼으로 새 탭 생성 (탭당 고객 3명 자동 생성)
2. 고객 정보 텍스트를 복사 후 페이지 빈 공간에 `Ctrl+V`
3. 자동으로 첫 번째 빈 고객 카드에 입력됨
4. 각 필드의 **복사** 버튼으로 클립보드에 복사해서 사용
